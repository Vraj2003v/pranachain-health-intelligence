# Contributing (Group 11)

## One-time git setup

So your commits show up under your own GitHub account instead of a generic name,
run this once on your machine inside this repo (replace with your own values):

```bash
git config user.name "Your GitHub username"
git config user.email "YOUR_ID+your-username@users.noreply.github.com"
```

Find your `YOUR_ID+username@users.noreply.github.com` address at:
GitHub → Settings → Emails → "Keep my email address private".

## Workflow

- Branch off `main` for anything non-trivial: `git checkout -b your-name/short-description`
- Open a PR into `main` so the group can see changes before they land
- Keep commits scoped and messages descriptive (what changed and why)
